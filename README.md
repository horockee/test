# DateType

A mobile-first dating personality quiz MVP built with Next.js, React and TypeScript.

## Current status

- Landing page and responsive visual design
- Eight-question interactive quiz
- Four original, entertainment-only result profiles
- Result preview and placeholder for the future paid report
- No database, accounts, payment processing or analytics yet

**Important:** The paid report is not live. The current result page explicitly says it is coming soon and does not collect payment.

## Run locally

Requirements: Node.js 20.9 or later.

```bash
npm install
npm run dev
```

Open http://localhost:3000.
